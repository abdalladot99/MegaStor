# MegaStor – Multi-Vendor E-Commerce Platform 🚀

## 📖 Overview
**MegaStor** is a **full-featured multi-vendor e-commerce platform** built using **.NET 8, ASP.NET MVC, Entity Framework, and SQL Server**.  
The system supports **vendor management, secure user authentication, electronic payment processing**, and **role-based access control (RBAC)**.

---

## 🌟 Key Features
- 🏬 **Multi-vendor system** with separate dashboards for vendors and a **central admin panel** for full control.  
- 👤 **Role Management:**  
  - **Main Admin:** Full control over users and admins, can assign and manage roles and permissions.  
  - **Admin:** Limited administrative privileges, manages vendors and products but cannot modify Main Admin settings.  
- 🛠️ **Product Management:** Add, edit, delete, and view products for each vendor with robust CRUD operations.  
- 🛒 **Shopping Cart, Wishlist, and Order Tracking** functionalities.  
- 💳 **Online order placement** with full payment gateway integration for secure transactions.  
- 🔐 **Secure authentication** using ASP.NET Identity with RBAC.  
- 🌐 **Social login integration:** Google, Facebook, GitHub, LinkedIn, Microsoft.  
- 🔑 **Password recovery** via email-based reset link.  
- 🎨 **Modern, responsive UI** built with HTML, CSS, JavaScript, and Bootstrap.  
- 📊 **Efficient data handling** using LINQ, Entity Framework, and SQL Server.  

---
## 🛠️ Tools & Technologies

- 🟣 **.NET 8 & ASP.NET MVC** – Core framework for building the web application.
- 🟢 **Entity Framework Core** – ORM for database management and data handling.
- 🗄️ **SQL Server** – Relational database for storing all application data.
- 🔐 **ASP.NET Identity** – Secure user authentication and Role-Based Access Control (RBAC).
- 💳 **Payment Gateway Integration** – For secure online payment processing.
- 📊 **LINQ** – Efficient querying of collections and database entities.
- 🌐 **HTML, CSS, JavaScript, Bootstrap** – For building a modern, responsive UI.
- 🔗 **Social Logins** – Integration with Google, Facebook, GitHub, LinkedIn, and Microsoft.
- ✉️ **Email Services** – For password recovery via secure reset links.
